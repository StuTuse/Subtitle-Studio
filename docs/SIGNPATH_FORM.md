## Tagline

面向 Windows 的开源字幕工作室，支持语音转写、字幕纠错、精修、烧录与导出。

## Description

Subtitle Studio 由 TuseCreation 开发维护，帮助视频创作者、教师及剪辑师完成字幕生产。用户可以使用本地或自行选择的语音服务生成字幕，再进行纠错、逐条精修、视频烧录及多格式导出。项目采用 GPL-3.0-only 开源许可，第三方组件保留各自许可；目前正在准备免费开源代码签名申请。
