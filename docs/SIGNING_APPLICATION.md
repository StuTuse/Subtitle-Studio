## 获批后接入

从 SignPath 获取组织、项目、签名策略及产物配置标识；将受限凭据存入托管平台的 Secrets，不提交仓库。按照基金会认可的来源验证方式接入自动构建，完成主程序签名 → 安装器封装/卸载签名 → 安装器签名 → 验签及真机安装冒烟，并保留人工审批。

本地签名后的正式交付仍须遵循 AGENTS.md：验证版本、重新构建及桌面快捷方式、运行打包版冒烟。不将「证书有效」等同于「SmartScreen 已免提示」。

申请入口：https://signpath.org/apply.html 。已通过浏览器读取正式表单：必填字段包括项目名、源码/主页链接、简介、分类、描述、信誉证据、构建系统、账号名/姓、邮箱、发现渠道；可选下载与隐私政策链接。必选同意行为准则及个人资料处理，另有可选营销通讯。未经用户在最终步骤确认，不代勾法律同意；营销通讯保持不勾选。是否提交成功以表单返回确认为准，不以填写字段算完成。
