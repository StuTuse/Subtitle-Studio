## Subtitle Studio 1.8.1

本地 Whisper 转写 → 大模型纠错 → 字幕编辑 → 多格式导出，全流程离线可用（纠错可选本地或云端模型）。

### 本次更新

- 修复「恢复默认设置」点确认后没反应：确认框改用原生消息框，同步返回、不再有卡住的可能。
- 恢复默认不再清除大模型接入数据：API Key、访问地址、模型名全部原样保留，其余设置照常归零。

### 下载与安装

点击下方的 **SubtitleStudio-1.8.1-setup.exe** 下载安装（约 90 MB）。

- 双击安装即可，**无需管理员权限**，装在你的用户目录下。
- 装完会自动启动一次：首次使用会进入「环境体检」，缺少的组件（如 GPU 加速所需的 CUDA 运行库）可一键补装，走国内镜像。
- 卸载时会询问是否保留模型缓存与工程文件，默认保留，下次装不用重新下模型。

> 需要 GPU 加速：装一个 NVIDIA 显卡 + 体检向导里一键装 CUDA 运行库即可，转写速度可快 5~20 倍；没有独立显卡也能用 CPU 跑。

### 系统要求

Windows 10 / 11（64 位）。
